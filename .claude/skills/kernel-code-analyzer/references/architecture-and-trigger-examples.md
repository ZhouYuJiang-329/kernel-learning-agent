# Architecture And Trigger Examples

这些例子只用于启发宏观层次图和触发场景写法，不是固定模板。生成文档时必须替换成当前分析对象自己的路径、函数名、事件来源和证据。

## syscall / VFS / 文件系统路径

层次图示例：

```text
用户态 syscall/read/write/ioctl
  └── VFS 层
        └── 具体文件系统或文件操作层
              └── [这段代码在这里]
                    └── 底层存储、内存对象或设备接口
```

触发场景示例：
- 当用户态执行某个系统调用时，VFS 根据文件描述符或路径找到对应 `file_operations`，再分发到当前函数。
- 当文件系统需要同步、回收或更新元数据时，上层 VFS 或 writeback 路径进入当前函数。

## sysfs / configfs 属性路径

层次图示例：

```text
用户态 read/write 属性文件
  └── VFS/kernfs/configfs 分发层
        └── 属性 show/store 回调
              └── [这段代码在这里]
                    └── 驱动私有状态或硬件配置
```

触发场景示例：
- 当用户态读取某个属性文件时，框架层调用对应 show 回调，当前代码把内核状态格式化成文本。
- 当用户态写入某个属性文件时，框架层调用对应 store 回调，当前代码解析字符串并修改驱动状态。

## platform driver probe/remove 路径

层次图示例：

```text
设备枚举 / 设备树匹配
  └── driver core
        └── platform_driver.probe/remove
              └── [这段代码在这里]
                    └── 资源映射、中断、子模块、硬件/固件接口
```

触发场景示例：
- 当内核发现设备节点与驱动 `compatible` 匹配时，driver core 调用 probe，当前代码初始化驱动运行状态。
- 当设备解绑或驱动卸载时，driver core 调用 remove，当前代码按初始化反方向释放资源。

## 调度器路径

层次图示例：

```text
任务状态变化 / tick / schedule
  └── 调度核心层
        └── 调度类回调或 CFS/RT/DL 子系统
              └── [这段代码在这里]
                    └── runqueue、调度实体、负载统计或硬件调频接口
```

触发场景示例：
- 当任务被唤醒、睡眠、迁移或抢占时，调度核心通过调度类回调进入当前代码。
- 当 CPU 需要选择下一个任务时，调度核心进入当前调度类的 pick 路径。

## CPU hotplug / stopper 路径

层次图示例：

```text
CPU 上线/下线请求
  └── CPU hotplug 状态机
        └── stopper / migration / teardown 阶段
              └── [这段代码在这里]
                    └── runqueue 迁移、任务冻结或 CPU 状态更新
```

触发场景示例：
- 当用户或系统策略触发 CPU 下线时，hotplug 状态机进入 teardown 阶段，当前代码负责迁移任务或清理 CPU 本地状态。
- 当需要在目标 CPU 上串行执行迁移动作时，stopper 线程调用当前函数。

## 固件通信 / 远端处理器路径

层次图示例：

```text
驱动业务请求
  └── 协议封装层
        └── SCMI/RPMSG/SMC/寄存器访问接口
              └── [这段代码在这里]
                    └── 固件、远端处理器或硬件寄存器
```

触发场景示例：
- 当驱动需要下发配置时，当前代码把语义化参数打包成协议消息并调用传输接口。
- 当驱动需要读取硬件/固件状态时，当前代码发送查询请求并把返回值转换成内核结构体字段。

## 锁 / 并发 / 等待路径

层次图示例：

```text
任务尝试获取资源
  └── 锁或等待队列框架
        └── 阻塞、唤醒或优先级处理逻辑
              └── [这段代码在这里]
                    └── waiters、owner、状态位或调度器接口
```

触发场景示例：
- 当任务获取锁失败需要阻塞时，锁框架进入当前代码记录等待关系。
- 当资源释放需要唤醒等待者时，当前代码从等待队列选择任务并交给调度器。
